# Haunted Escape - Godot 4.2 starter (untested)

Open `project.godot` in Godot 4.2 or newer. It runs a small dark arena with a first-person player and one ghost of each kind.

Controls: WASD + mouse (click to capture), Shift = run, Q = camera flash. On a phone: drag the left half to move, the right half to look.

This starter was written without being run in Godot, so expect to fix small errors. It contains no art or audio.
See GODOT_PORT_PLAN.md for the full porting plan.
